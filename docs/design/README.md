# Godkänd design (referens)

Elva mobilskärmar (390 × 844) som visar hur appen ska se ut. Filerna är referens för layout, färger, texter och mått. De ska inte köras eller importeras i appen.

Läs markupen inuti `<x-dc>` och de inline-stilar som står där. `{{ ... }}` är platshållare som fylls av skriptet längst ner i samma fil.

| Fil | Skärm |
|---|---|
| Main.dc.html | 1 Dashboard |
| Pass.dc.html | 2 Pass (blad) |
| Planning.dc.html | 3 Planning, veckan |
| Live.dc.html | 4 Live |
| Tranare.dc.html | 5 Närvaro |
| Atlet.dc.html | 6 Atlet, Hem |
| Start.dc.html | 7 Planera pass, start |
| Bygg.dc.html | 8 Bygg passet |
| Valj.dc.html | 9 Välj övningar |
| NyOvning.dc.html | 10 Ny övning med bild |
| Bibliotek.dc.html | 11 Bibliotek |

Exempeldata i filerna (namn, tider, antal) är påhittad och ska inte kopieras in i appen.
